# AETHERIS
An app and web page that turns idle large-screen devices into full-screen desktop ornaments.

## ✨ Core Features
- 🌤️ Dynamic weather system (sunny, rainy, thunderstorm, and snowy transitions with particle effects)
- 🕰️ Minimalist clock and date display (supports the Minguo calendar)
- 🎵 Ambient sounds and wind chimes synthesized entirely with frontend code (Web Audio API)
- 🌍 Extensive localization (including Hokkien, Hakka, Cantonese, and Wu, plus North Korean and South Korean language variants with special easter eggs)
- 📺 Perfectly adapts to phones, tablets, computers, and smart TVs (compatible with iPhone 6 / iOS 12)
